POS Community IoT

Route Point of Sale receipt and preparation printing to Community IoT devices on Odoo 17 Community.

What this module provides

  • POS receipt routing to Community IoT printers
  • Preparation printer integration through Community IoT
  • Per-POS IoT Box and printer assignment
  • Server-side Community IoT job creation

Supported flow

  • Create and configure an IoT Box in Odoo
  • Connect the external Community IoT Agent
  • Assign receipt and preparation printers in POS
  • Print through Community IoT devices

Notes

This repository contains only the Odoo addon. The external Community IoT Agent is distributed separately.
